# 05 消息组件与结果

## 导入

```python
from astrbot.api.message_components import Plain, Image, At, Reply, Node, Face, Record, Video

import astrbot.api.message_components as Comp
```

`astrbot.api.message_components` 直接 `from astrbot.core.message.components import *`，是公开稳定 API。

### Image 的四种构造

```python
Image(file="https://example.com/a.png")          # 注意：file 是必填位置参数
Image.fromURL("https://example.com/a.png")       # 仅接受 http(s)
Image.fromFileSystem("/abs/path/a.png")          # 转成 file:// URI，同时设 path
Image.fromBase64("iVBORw0KGgo...")               # 转成 base64://
Image.fromBytes(b"...")                          # 字节 → base64
```

`Image` 属性：`file`、`url`、`path`、`_type`。⚠️ `__init__` 签名是 `__init__(self, file: str | None, **_)` —— **`file` 必填**，不能写 `Image(url=...)`；要给 url 就构造后赋值：

```python
img = Image(file="")
img.url = "https://example.com/a.png"
```

### Reply.chain（4.29.4 图片修复关键）

```python
for comp in event.get_messages():
    if isinstance(comp, Reply) and comp.chain:
        for seg in comp.chain:          # 引用消息里的原始段
            if isinstance(seg, Image):
                ...
```

引用消息里的图片**不会出现在顶层消息链**，遍历 `Reply.chain` 才能拿到。这是很多图片类插件漏处理的场景。

## 消息链 MessageChain

`MessageChain`（`core/message/message_event_result.py`）是一个 dataclass，核心字段 `chain: list[BaseMessageComponent]`。链式方法：

| 方法 | 作用 |
|---|---|
| `.message(str)` | 追加 Plain |
| `.at(name, qq)` / `.at_all()` | 追加 At |
| `.error(str)` | 追加错误文本 |
| `.url_image(url)` / `.file_image(path)` / `.base64_image(b64)` | 追加图片 |
| `.use_t2i(bool)` / `.use_markdown(bool)` | 渲染开关（`None` = 跟随用户设置） |
| `.get_plain_text(with_other_comps_mark=False)` | 提取纯文本 |
| `.squash_plain()` | 合并相邻 Plain |
| `.derive(chain=None)` | 复制元数据生成新链 |

## 返回结果：三种写法

```python
# 1) 纯文本（最常用）
yield event.plain_result("你好")

# 2) 单张图片（http 开头走 url_image，否则当本地路径）
yield event.image_result("/abs/path/a.png")

# 3) 自定义消息链
from astrbot.api.message_components import Plain, At, Image
yield event.chain_result([
    At(qq=event.get_sender_id()),
    Plain(" 这是你的图："),
    Image.fromFileSystem("/abs/path/a.png"),
])
```

也可以用 `MessageEventResult` 的链式 API：

```python
from astrbot.api.event import MessageEventResult
yield MessageEventResult().message("第一行").at("某人", 123456)
```

`MessageEventResult` 继承 `MessageChain`，额外有：

- `stop_event()` / `continue_event()` / `is_stopped()`
- `set_async_stream(gen)` 流式输出
- `set_result_content_type(typ)`、`is_llm_result()`、`is_model_result()`

`event.set_result(...)` 可直接设置结果（接受 `MessageEventResult | str`）。

## 主动发送消息

```python
# 在当前会话立即发一条（不经过结果管线）
await event.send(MessageChain().message("处理中..."))

# 按会话来源主动发（可用于定时任务）
from astrbot.api.event import MessageChain
ok = await self.context.send_message(
    event.unified_msg_origin,
    MessageChain().message("定时提醒"),
)
```

`send_message` 返回 `bool`；参数是 `MessageChain`（不是列表）。官方注释提示：QQ 官方 API 平台（`qq_official`）不支持主动消息。

## 平台适配矩阵（发送消息能力）

| 平台 | At | Plain | Image | Record | Video | Reply | 主动消息 |
|---|---|---|---|---|---|---|---|
| QQ 个人号 (aiocqhttp) | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| Telegram | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| QQ 官方接口 | ❌ | ✅ | ✅ | ❌ | ❌ | ❌ | ❌ |
| 飞书 | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| 企业微信 | ❌ | ✅ | ✅ | ✅ | ❌ | ❌ | ❌ |
| 钉钉 | ❌ | ✅ | ✅ | ❌ | ❌ | ❌ | ❌ |

补充：

- aiocqhttp 还支持 `Poke`、`Node(s)` 合并转发。
- QQ 官方接口、钉钉发送时平台强制带 `At`。
- 钉钉图片仅支持 http 链接。
- aiocqhttp 对 `Plain` 会自动 `strip()` 空格换行，需要保留可用零宽空格 `\u200b`。

## 让 LLM 参与（request_llm）

```python
yield event.request_llm(
    prompt="请总结这张图",
    system_prompt="你是一个图像分析助手",
    image_urls=["/abs/path/a.png"],     # 支持 http / base64:// / 本地路径
)
```

`request_llm` 返回一个 `ProviderRequest`，`yield` 它即把请求交回管线。参数含 `prompt`、`system_prompt`、`image_urls`、`audio_urls`、`contexts`、`conversation`、`tool_set` 等（`session_id` 已过时，留空）。

## 常见错误

| 现象 | 原因 |
|---|---|
| `TypeError: Image.__init__() missing ... 'file'` | `Image` 的 `file` 是必填位置参数 |
| 图片发不出去 | 路径不是绝对路径 / 跨容器不可读；优先用 `Image.fromBase64` 或 `data:` URI |
| 引用消息里的图片没被处理 | 只遍历了顶层 `get_messages()`，漏了 `Reply.chain` |
| `plain_result` 里文本首尾空格被吞 | aiocqhttp 的 `strip()` 行为，用 `\u200b` 规避 |
